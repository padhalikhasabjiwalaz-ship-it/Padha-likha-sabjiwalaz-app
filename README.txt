पढ़ा-लिखा सब्जीवालाज हिसाब ऐप

फाइलें:
- index.html: ऐप
- manifest.webmanifest: होम स्क्रीन इंस्टॉल जानकारी
- sw.js: ऑफलाइन कैश
- icon-192.png और icon-512.png: ऐप आइकन

ज़रूरी:
PWA इंस्टॉल और ऑफलाइन कैश के लिए इन फाइलों को HTTPS वेबसाइट पर होस्ट करना होगा
(या localhost पर चलाना होगा)। केवल फोन में HTML फाइल खोलने से Install App/Service Worker
काम नहीं करेगा। रिकॉर्ड उसी ब्राउजर के localStorage में रहते हैं; ब्राउजर डेटा मिटाने पर
रिकॉर्ड मिट सकते हैं, इसलिए ऐप का बैकअप नियमित डाउनलोड करें।
